# 01 - NCBI and GenBank Sequence Retrieval

This module focuses on practical hands-on retrieval of biological sequences.

### What I did
- Retrieved nucleotide and protein sequences using NCBI Entrez
- Practiced accessing GenBank records and understanding their format (FASTA, GenBank)
- Learned to identify key information like accession number, organism, gene name

### Tools Used
- NCBI, GenBank, Entrez 

### Skills Gained
Hands-on experience in navigating biological databases to fetch required sequence data for analysis.
